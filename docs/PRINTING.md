# Printing guide

## Recommended starting profile

| Setting | Media keychains | Trailer Swift v4 |
| --- | --- | --- |
| Nozzle | 0.4 mm | 0.4 mm |
| Layer height | 0.16 mm | 0.16 mm |
| Walls | 4 | 4 |
| Top/bottom layers | 5 | 5 |
| Infill | 25-35% gyroid | 25-35% gyroid |
| Supports | Off | Organic, build plate only |
| Wall generator | Arachne | Arachne |
| Top pattern | Monotonic | Monotonic |

PLA Tough or PLA+ is preferred for keyring durability and the Trailer Swift
hair and guitar tips.

## Orientation

- Cassette, floppy, and VHS print flat with detailed faces upward.
- Trailer Swift prints upright on the circular base.
- Use a clean build plate and a 5 mm brim for the first Trailer Swift test.
- The combined v6 plate mixes flat objects and the upright figure. Enable
  support for the Trailer Swift object only when possible.

## Production gate

Print one of every single-test file before a batch. Check the thickest intended
split ring, all raised lettering, rear NFC adhesion, scan range, pocket wear,
and a one-meter drop onto a hard floor.
