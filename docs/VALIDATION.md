# Validation standard

The generator records mesh dimensions, watertightness, body count, boundary
edges, non-manifold edges, NFC geometry, and intended support strategy in the
release QA report.

Before a release is called production-final, complete these physical checks:

- Slice every individual test file without model errors.
- Print one sample in the intended production filament.
- Confirm every media eyelet accepts the thickest intended split ring.
- Confirm the floppy rear details print cleanly without reopening the shell.
- Confirm the VHS reads immediately as a VHS at arm's length.
- Confirm Trailer Swift stands without rocking and survives a one-meter drop.
- Confirm the 25 mm tag adheres fully and scans from common phone positions.
- Carry each keychain for at least three days and inspect the eyelet and relief.

Digital checks are necessary, but a physical print remains the final gate.
