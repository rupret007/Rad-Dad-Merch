# Rad Dad Retro Riot v6

**Old media. Loud band. One tap.**

## Print first

Use the individual `SINGLE_TEST` 3MF files before the combined plate. The media pieces print flat without supports. Trailer Swift is an upright desk collectible and needs organic supports from the build plate.

## What changed

- VHS v3 now has a dominant hinged tape door, framed reel bay, authentic hubs, center gauge, five screws, and compact label.
- Floppy v18 restores rear shell hardware without reducing the 25 mm NFC contact area.
- Trailer Swift v4 is a solid-base collectible with toy-like depth, a faux bobble spring, front nameplate, and underside NFC placement.
- Cassette v36 remains unchanged because its current proportions and compact eyelet are already proven.

## Make the tap obvious

Use the supplied 25 mm TAP TO PLAY artwork as a non-metal overlay on the programmed rear NFC tag. A 20-up print sheet and handoff card are included in `guides`. Trailer Swift also says TAP THE BASE on the stage top.

## Batch gate

Physically test one of each model, every NFC tag, and the thickest intended split ring before producing a batch.
