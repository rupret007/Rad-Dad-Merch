# Rad Dad Retro Riot NFC Collection

**Old media. Loud band. One tap.**

This private repository contains the working source, print-ready files, and
production notes for Rad Dad's punk-rock NFC collectibles.

## Current release

The current release is **Retro Riot v6**:

| Design | Version | Purpose |
| --- | --- | --- |
| Rad Dad cassette | v36 | Authentic cassette keychain with rear NFC tag |
| Rad Dad floppy | v18 | 3.69 MB floppy keychain with developed rear shell |
| Rad Dad mini VHS | v3 | Unmistakable VHS keychain with tape door and reel bay |
| Trailer Swift collectible | v4 | Upright punk desk toy on a solid circular NFC base |

Start with [the v6 release guide](release/v6/README.md). The combined A1 Mini
plate is in `release/v6/3mf`, while individual test plates are provided for
each design.

## Repository layout

```text
docs/          Design, NFC, printing, and validation guidance
release/v6/    Current generated 3MF, STL, previews, guides, and QA files
src/           Repeatable model-generation source
tools/         Release-integrity checks
```

## Important distribution notice

This repository is a **private development archive**. Some media shells are
derivatives of user-supplied MakerWorld models. Do not make the repository
public, publish model files, or create public GitHub release attachments until
the third-party permissions documented in
